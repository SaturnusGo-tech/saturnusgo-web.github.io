Clasificación técnica

Mercancías peligrosas

Umbrella Home no es un transportista habilitado para mercancías peligrosas. En un pedido estándar se prohíben todas las clases que requieren condiciones especiales, rotulado, embalaje, documentos o autorización.

Cómo se aplica esta lista

  • La lista no es exhaustiva. Si la ley argentina, una norma provincial, un regulador, una licencia o las condiciones de seguridad exigen autorización especial, el artículo no se acepta en un pedido estándar de Umbrella Home.
  • El prestador de Umbrella Home puede rechazar un artículo cuando el embalaje está dañado, el contenido no se declara, el rotulado es inconsistente, hay olor, fuga, presión, señales de manipulación o riesgo para personas, bienes o ambiente.
  • Si un artículo solo es lícito mediante transportista habilitado, farmacia, transporte sanitario, régimen de armas, cadena controlada o venta con control de edad, el pedido debe cancelarse o redirigirse a un proceso autorizado separado.
