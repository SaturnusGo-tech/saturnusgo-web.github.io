Test cases

From a description to a test case

Describe the check in your own words. Falcon AI helps refine and format the text. Shared steps save you from writing the same actions again.

Save the scenario, preconditions and expected results in the right folder. Your team can use it in runs and test suites.

Test runs

One run. A clear queue for every tester.

Add whole folders or select individual scenarios. Assign the checks and start a run for the environment you need.

Filter by assignee to see both their checks and their execution order. Each tester can work through their part of the run.

Test suites

Build a suite once. Run it again.

Group checks for smoke testing, regression or a part of your product. Pick the cases from the same folder tree you use in the repository.

Adjust the selection and create fresh runs from it. Each run retains its own results.

Defects

A bug report with the testing context

Create a bug report directly from a failed step. Keep the scenario, actual and expected results, assignee and discussion together.

When the fix is ready, return to the linked case, run the verification and confirm the result.

Results

See the checks behind each metric

Track the team's queue, run results and open defects on the project dashboard.

Open the cases, runs or bug reports behind a metric to understand what needs attention next.

Integrations

Development in your tracker. Testing in Falcon.

Send defects to YouTrack with their testing context. Linked statuses show the team when a fix is ready to verify.

Open the developer's issue from Falcon and return through the backlink. Once you confirm the retest, Falcon sends the result to YouTrack.

Before you get started

How do we get started with Falcon?

Contact us on Telegram to discuss your team size, integrations and terms. Once agreed, we create your company workspace and give your administrator access.

Can we bring our existing test cases?

Yes. The repository supports importing and exporting cases. Supported formats and field requirements are listed in your workspace's Help section.

How does the team verify fixes?

Link test cases to a bug report. When the defect is ready for testing, Verify fixes opens a run with the relevant scenarios.

How do team members get access?

Your company administrator adds team members and assigns roles. The team signs in at your company's address. The number of seats is agreed when you join.
