Platform fit

A partner should live where the user already has intent.

A hotel can connect to arrival rides. A restaurant can connect to discovery and delivery. A venue can connect to saved places and route planning. The platform is strongest when the integration feels obvious.

Surfaces

What the platform can expose first.

ListingA clear public partner profile.Name, category, location, contact path, quality signals, and the user action that matters most.→
RouteTransport attached to the partner moment.Let users move to the place, return from it, or plan the next stop without leaving the SaturnusGo flow.→
SaveCollections that keep future demand alive.People can save places, revisit collections, and return to the partner when the city plan becomes active.→
OrderDelivery and request scenarios.For services that need logistics, the partner surface can guide the user toward delivery or a practical request.→

Build order

Start narrow, prove the scenario, then expand.

The first version does not need a heavy integration. It needs a useful placement, a clean action, and enough operational clarity to test real demand.
