Partners / Trust

Trust is the product, not a footnote.

Partner visibility only works if the user feels the service is clear, current, reachable, and worth acting on.

Quality bar

A trusted partner page should reduce uncertainty.

Users need to know what the partner offers, where it is, how to reach it, what happens next, and whether the action belongs in their current plan.

Standards

The practical trust layer.

AccuracyCurrent information comes first.Names, locations, categories, availability, and primary actions must stay clear enough for a user to decide quickly.→
SupportContact paths should be obvious.Partner, user, compliance, and support paths need to be separated so every issue has a clean owner.→
PrivacyUse only the data needed for the scenario.The integration should ask for less, explain more, and avoid turning a useful product moment into surveillance.→
ExperienceThe product should stay calm.No aggressive layouts, noisy blocks, or unrelated data. Trust is easiest when the interface is easy to read.→

Principle

If the partner moment is not useful, it does not ship.

That rule keeps the partner program aligned with the main SaturnusGo product identity.
